Latihan Percabangan & Perulangan

Tiga program kecil: penilai nilai (if / else if), penghitung bilangan (for), dan penjumlah digit (while).

1. Penilai Nilai

Masukkan nilai 0–100. Ada 5 kondisi: A, B, C, D, dan E.

Hasil akan muncul di sini.

2. Daftar Bilangan (for)

Masukkan angka N. Program menampilkan 1 sampai N lengkap dengan keterangannya.

    3. Jumlah Digit (while)

    Masukkan bilangan bulat positif. Program menjumlahkan semua digitnya.

    Hasil akan muncul di sini.
